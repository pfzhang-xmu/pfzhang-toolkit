# Image-to-PPT 还原策略

## 核心原则：三层分解

画面的每个像素属于以下三层之一：

| 层级 | 内容 | 实现方式 | 可编辑性 |
|---|---|---|---|
| **A — 视觉资产** | 复杂插图、照片、图表、图标、装饰背景 | 信息关键型→原图裁切；装饰氛围型→AI生成PNG | 可替换 |
| **B — 结构** | 矩形、卡片、面板、线条、箭头、分隔线、徽章 | PPT 原生形状 | 完全可编辑 |
| **C — 内容** | 所有可读文字：标题、标签、正文、页码 | PPT 原生文本框 | 完全可编辑 |

**核心原则：文字绝不烤进图片。复杂视觉不用形状硬画。整页截图绝不用作背景。**

## 还原策略

1. 先识别页面结构，将画面拆成"复杂视觉资产层(A)"、"结构层(B)"和"可编辑内容层(C)"。
2. A层视觉资产根据信息属性进一步分类：
   - **信息关键型**（品牌Logo、数据图表、照片、架构图、UI截图）→ 原图裁切，保证100%保真
   - **装饰氛围型**（纹理、抽象背景、装饰图标、光效、波浪纹样）→ AI生成高清PNG，画质更优
3. B层结构使用 PPT 原生形状、线条、基础图形重建。
4. C层内容使用 PPT 原生文本框重建，保持字体气质、字号层级、颜色、位置。
5. 如果原图文字需要改成可编辑文本，请使用背景色、渐变近似或局部遮罩覆盖原图文字，再叠加可编辑文本，避免重影。
6. 品牌 Logo、商标、产品 UI、人物、商品图、官方图标 **必须**原图裁切，不要手绘或AI生成。
7. 简单线条、分隔线、基础几何框、轻量标签、简单按钮、简单色块、页码、基础表格 → 重建为可编辑 PPT 元素。
8. 如果图表数据无法从图片准确反推，请按视觉比例近似重建，并在说明里标注"数据为视觉近似"。

## AI 生图 vs 原图裁切 判断标准

**核心问题：如果这个元素被替换成相似但不完全相同的版本，熟悉原图的人会不会发现？**

- **会 → 原图裁切**（信息关键型）
- **不会 → AI 生成**（装饰氛围型）

| 原图裁切 (crop_region.py) | AI 生成 (imagen-skill) |
|---|---|
| 品牌 Logo、商标 | 装饰纹理（网格、点阵、电路线） |
| 数据图表（柱状图、折线图） | 抽象背景（渐变光晕、科技线条） |
| 产品照片、人物照片 | 简单装饰图标（文件夹、信号、齿轮） |
| 架构图、流程图（特定拓扑） | 氛围图（科幻场景、光影效果） |
| UI 截图、软件界面 | 装饰分隔纹样、边角装饰 |
| 地图、科学插图 | 波浪/曲线装饰 |

详见 [image_gen_guide.md](image_gen_guide.md) 的 prompt 模板和规范。

## 文字重建要求

1. 尽量保持原图的字体气质、字号层级、字重、颜色、行距、字距、对齐方式和位置。
2. 如果无法识别字体，请选择最接近原图视觉气质的系统字体。
3. 中文优先选择接近原图的黑体/苹方/思源黑体/微软雅黑等风格；英文和数字选择与原图接近的无衬线或衬线字体。
4. 不允许出现明显错字、漏字、换行错误、文本溢出、文字重叠或位置漂移。
5. 关键词高亮、不同颜色文字、粗细变化、编号、引导、单位、标点都要尽量保留。
6. 如果完全按原图排版会导致 PPT 原生文字观感明显变差，可以在不改变含义的前提下做轻微排版微调。

## 设计还原要求

1. 保持原图的版式、比例、视觉重心、阅读顺序和留白节奏。
2. 保持原图的颜色、对比度、明暗关系、光源方向、阴影强度和空间层次。
3. 保持复杂视觉区域的原始质感，不要替换成默认 PPT 图标、默认图表、默认阴影或模板化卡片。
4. 所有元素的位置、大小、层级、裁切方式、圆角、描边、阴影、透明度和对齐关系要尽量贴近原图。
5. 如果页面有图表、流程图、矩阵、时间线、对比图、循环图或信息图，请优先保留其视觉关系和阅读逻辑。
6. 如果某个视觉元素既可以编辑又会显著降低质感，请优先保留为图片，但主要文字除外。

## 输出与检查

1. 输出一个 PPTX 文件。
2. 同时渲染 PPTX 预览图，与原始图片做视觉对照。
3. 如果预览图和原图在质感、比例、间距、颜色、层级或整体观感上差距明显，请继续迭代修改。
4. 最终请简要说明：
   - 哪些元素是可编辑文本/形状/图表；
   - 哪些元素是从原图裁切或提取的图片素材；
   - 哪些文字因为嵌入复杂视觉区域而保留为图片；
   - 哪些地方为了保留质感而牺牲了可编辑性。
