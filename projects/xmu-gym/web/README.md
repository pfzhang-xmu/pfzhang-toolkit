# Web 前端

纯静态：没有构建链、没有打包器。`app/server.py` 直接把这里的文件当静态资源发。

```
web/
  index.html    结构（报头 / 三个标签 / 两个弹层）
  styles.css    全部样式与设计 token
  app.js        本机桥 + 三个面板的渲染与动作
  catalog.js    场馆目录
  assets/       插画、空态贴图、图标
```

## 本地预览

```sh
python -m app.server --demo --port 1431
```

`--demo` 用假数据，不读微信、不提交；页面右上角会显示「演示数据」。

## 约束

- 只调 `/api/invoke`，命令名与 `app/server.py` 一致；不要在前端模拟预约结果。
- 预约、取消、入场码都是真实副作用。取消必须按住 1 秒，提交前必须过确认框。
- 只读失败（查场次、读订单）不要说成「提交结果不明」，页面用 `explain()` 分开措辞。
- 颜色只用来表示状态（叶绿 / 姜黄 / 珊瑚红）；不引外链字体；图片只从本地 `assets/` 取。
