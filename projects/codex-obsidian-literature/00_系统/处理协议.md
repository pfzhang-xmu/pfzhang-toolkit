# PDF 文献处理协议

当 Codex 项目对话消息包含一个或多个 PDF 时自动触发；文字内容作为补充要求。普通不含 PDF 的消息不触发本流程。

1. PDF 是事实主要来源；DOI/Crossref 只用于补齐书目信息。
2. 读取本协议、[[审查清单]] 和三个模板。
3. 按 DOI 优先、规范化标题加年份其次匹配已有笔记，保留人工内容。
4. 生成或更新一份 Paper Note、一份 ML/AI Workflow Note，以及有跨论文复用价值的方法、流程、批判和启发卡。
5. 关键结论加入 `p. X, Section Y: "短引文"` 证据锚点；不确定内容写 `待核实` 或 `缺失`。
6. 所有新笔记保留 `review_status: needs-review`。
7. 写入完成后执行 `python3 scripts/research_search.py index`。索引失败不得回滚笔记。
8. 处理结束返回简明报告：生成文件、证据状态、索引状态、待核实事项和错误。

## 输出目录

- `10_论文/`：Paper Note 与 ML Workflow Note
- `20_知识/方法/`、`流程/`、`批判/`、`启发/`：原子知识卡
- `90_附件/论文/`：PDF 原文
