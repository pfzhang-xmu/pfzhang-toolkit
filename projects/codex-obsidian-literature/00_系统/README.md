# 电催化 + AI/ML 文献知识库

这是本 vault 的入口。知识库服务于电催化研究中的机器学习、人工智能和 LLM 方法检索，优先记录可复用的方法、完整流程、批判性判断和研究启发。

## 快速开始

1. 将 PDF 放入 `90_附件/论文/`。
2. 在 Claudian/Codex 中发送：`处理 [[PDF文件名.pdf]]`。
3. 代理按照 [[处理协议]] 创建或更新三类笔记，并自动更新向量索引。
4. 打开 [[研究仪表盘]] 检查待核实字段和索引状态。
5. 人工核对 PDF 后，把 `review_status` 从 `needs-review` 改为 `reviewed`。

## 目标期刊自动发现

- 处理协议：[[处理协议]]
- 审查清单：[[审查清单]]

每日任务以 RSS 发现目标期刊文章，只对高置信度相关原创研究尝试合法公开 PDF 下载。无法下载或需要人工判断的记录进入 Dashboard，不会在缺少 PDF 时生成论文笔记。

## 规范

- PDF 是事实来源；AI 负责提取、组织、连接和提出启发。
- 关键结论必须带页码/章节和短引文。
- 原文没有提供的信息写 `待核实`，不得猜测。
- 一篇论文只保留一个 Paper Note，重复处理时更新原卡。
- 材料、反应和性能只记录理解 AI/ML 方法所需的最小背景。

## 文件夹

- `00_系统/`：模板、处理协议、审查清单和仪表盘
- `10_论文/`：论文卡和 ML/AI 流程卡
- `20_知识/`：方法、流程、批判、启发原子知识
- `90_附件/论文/`：PDF 原文
