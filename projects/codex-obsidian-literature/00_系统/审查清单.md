# 论文审查清单

## 事实与证据

- [ ] 标题、作者、年份、期刊和 DOI 已核对
- [ ] 主要结论均有页码/章节和短引文
- [ ] 明确内容、推断内容和缺失内容已区分
- [ ] 待核实事项已列出，没有猜测值

## ML 流程

- [ ] 研究问题和预测目标明确
- [ ] 数据来源、样本量、标签和清洗方式已记录
- [ ] 特征、预处理和数据泄漏风险已检查
- [ ] train/validation/test 划分和交叉验证已记录
- [ ] 基线、模型、超参数和调参策略已记录
- [ ] 评价指标与任务匹配，报告了必要的误差/不确定性
- [ ] 解释性、外部验证和适用范围已检查
- [ ] 代码、数据和复现条件的缺失情况已标记

## 可迁移性

- [ ] 至少提炼一条方法或流程卡（若确有复用价值）
- [ ] 至少记录一条对当前研究的启发或明确写“暂无”
- [ ] 批判结论与原文证据分开书写

## 自动发现来源（适用时）

- [ ] Paper Note 中的 DOI 与 PDF/书目信息一致
- [ ] `zotero_item_key` / `zotero_uri` 仅在读回验证后填写
- [ ] `Processed` 未被误写为人工 `reviewed`
